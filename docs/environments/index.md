# Environments

Gym.NET's environments come in four families: classic control, Box2D, toy text and MuJoCo. The gallery plays 24 of
them as the showreel recorded them. Select a cartridge to watch it on the screen with the episode's seed, steps and
return and how to play it; READ THE MANUAL opens the env's page, which the sidebar also lists by family.
